# FX Roadmap Status — 現在地確認

fx-ai-traderのロードマップ達成状況を、Codexに渡せる粒度で整理する。

## 手順

1. `CLAUDE.md` を読む。
2. `knowledge-base/wiki/syntheses/roadmap-v2.1.md` を読む。
3. `knowledge-base/wiki/index.md` を読む。
4. 最新の `.ai/decisions/` と `.ai/runs/` を確認する。
5. `git status --short` を確認する。

## 出力

以下を短く出す。

- 現在のGate
- 達成済み条件
- 未達条件
- 本番リスク上位3つ
- Codexに渡すべき次タスク候補3つ
- 最優先候補1つと理由
