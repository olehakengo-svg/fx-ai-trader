## 4.2 3 BT runners

各 runner は `s4_connors_raschke.py` の構造を踏襲:

- locked grid (post-hoc selection 罠回避)
- primary cell を spec で固定
- Bonferroni m, BEV_WR を CLI 出力
- WF folds≥3 + null bootstrap p
- 出力: trade-list parquet + daily-pnl parquet + verdict MD/JSON

各 runner の **primary cell**:

- SFT-A `month_end_usd_rebalance_short`: window=`fix-30min..fix+30min`, exit=`60min`, pairs=USDJPY/EURUSD/GBPUSD pooled
- SFT-B `tokyo_fix_955_jpy_demand`: window=`fix-30min..fix`, exit=`60min`, pair=USDJPY only
- SFT-C `quarter_end_jpy_repat`: window=`last 5 business days of Mar/Sep`, exit=`month_end 17:00 GMT`, pair=USDJPY only

## 4.3 Tests `tests/test_sft1_*.py`

各 BT に最低 4 テスト: setup detection, entry/exit timing 整合, locked grid 改竄ガード, holiday/weekend 除外。

## 4.4 Slippage realism

spec doc R1/R2 に従い、月末 fix は spread を **通常の 2.0x** で乗せる pessimistic baseline を併設。BT は 2 種類 (normal spread / 2x spread) 走らせて両方の verdict を report に併記。

(NSG-1 が完成していれば実値、未完了なら DEFERRED と記載)
