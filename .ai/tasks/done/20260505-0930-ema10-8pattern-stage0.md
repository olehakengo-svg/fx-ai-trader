### コア関数（純関数で実装、I/O は CLI レイヤのみ）

```python
def resample_m5_to_m15(df_m5: pd.DataFrame) -> pd.DataFrame:
    """M5 → M15 OHLC リサンプル。lookahead bias 防止のため closed='left', label='left'。"""
    return df_m5.resample('15min', closed='left', label='left').agg({
        'Open': 'first', 'High': 'max', 'Low': 'min', 'Close': 'last', 'Volume': 'sum'
    }).dropna()


def is_bull_pinbar(open_, high, low, close) -> bool:
    body = abs(close - open_)
    rng = high - low
    if rng == 0:
        return False
    lower_wick = min(open_, close) - low
    return lower_wick >= 2 * body and body / rng <= 0.4 and close > open_


def is_bull_hammer_bear(open_, high, low, close) -> bool:
    body = abs(close - open_)
    rng = high - low
    if rng == 0:
        return False
    lower_wick = min(open_, close) - low
    return lower_wick >= 2 * body and close < open_


def is_bullish_engulfing(prev_open, prev_close, open_, close) -> bool:
    return (close > open_
            and open_ <= prev_close
            and close >= prev_open
            and prev_close < prev_open)


def is_bullish_harami_breakout(prev_open, prev_close, prev_high, prev_low, open_, close) -> bool:
    # 前足陰線 + 前足の low が直前 swing low を更新 + 現足が前足 high を上抜け
    if prev_close >= prev_open:  # 前足が陽線なら不成立
        return False
    return close > open_ and close > prev_high
```

Short パターンは対称（high/low, close/open, prev_close/prev_open を反転）で別関数として実装。

### Critical implementation notes

1. **No lookahead**: Entry は `df['Open'][t+1]` （t+1 の open）。t の close は使わない。
2. **Spread/slippage application**:
   - Long entry: `entry = open + spread + slip`
   - Long exit: TP/SL hit price - spread - slip （buy 側支払いと sell 側受取の両方を上乗せ）
   - Short は対称
3. **SL/TP intra-bar pessimism**: 同一 bar で SL と TP の両方が hit する場合、**SL を優先**（保守的）
4. **Swing high/low (fractal-2)**:
   - Swing high at index i: `df['High'][i] > max(df['High'][i-2:i])` AND `df['High'][i] > max(df['High'][i+1:i+3])`
   - Long の TP: t-1 から `tp_lookback=20` 本を遡って最も近い swing high。なければ entry + 1.5 × ATR
   - Long の SL: t-1 から 20 本遡って最も近い swing low。なければ entry - 1.0 × ATR
5. **Weekend filtering**: Friday 22:00 UTC 以降〜Sunday 22:00 UTC 未満の bar は除外
6. **N counting**: Trend cross 強制 close は 1 trade としてカウント
7. **PF 計算**: `sum(positive_pip_pnl) / abs(sum(negative_pip_pnl))`、勝ち負け 0 の場合は `pf = inf` を 99.0 にクリップ

### 出力 metrics（pre-reg §Acceptance criteria の JSON schema 厳守）

- `n` (int): trade 総数
- `wr` (float): 勝率 0-1
- `wilson_lo_95` (float): Wilson 95% CI 下限。`scipy.stats.binomtest(k, n, alternative='two-sided').proportion_ci(0.95)` の low
- `pf` (float)
- `ev_pip_per_trade` (float)
- `avg_rr` (float): 勝ち trade の avg pnl / 負け trade の avg pnl 絶対値
- `max_dd_pip` (float)
- `max_dd_pct` (float): 単利 1 unit = 100k で計算
- `sharpe` (float): trade pnl 系列の Sharpe（年率化、252 で）
- `profit_year_concentration` (float): max(positive_yearly_pnl) / sum(positive_yearly_pnl)
- `yearly_breakdown` (list): 年別 n / pf / ev_pip
- `data_quality.missing_pct`: M15 リサンプル後、weekend filtered の上で expected_bars との差分 %
