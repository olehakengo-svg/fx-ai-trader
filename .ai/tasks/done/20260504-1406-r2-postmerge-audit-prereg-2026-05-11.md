## 1. 仮説

**H1**: 15-cell LOCK 適用後 7 日間で TRUE_LIVE bucket (`is_shadow=0 AND oanda_trade_id != ''`) 内の **新規 N (post-LOCK)** が aggregate raw Kelly ≥ 0 / EV ≥ 0 を実測する → Gate 0 ACCEPT。

**H0**: post-LOCK 新規 N で raw Kelly < 0 継続 → Gate 0 REJECT、追加 cell-level demote が必要。

ロードマップ前進条件: H1 採択時のみ A3-simple dispatch + Gate 1 0.3x lot へ進める。

## 3. 統計条件 (pre-registered LOCK)

判定基準は本ファイル commit 時点で **凍結**。post-hoc 変更禁止。

| 指標 | 計算式 | ACCEPT | NEEDS_MORE_EVIDENCE | REJECT |
|---|---|---|---|---|
| N_post_lock (TRUE_LIVE) | post-LOCK 新規 trades | ≥ 30 | 15 ≤ N < 30 | < 15 |
| Aggregate raw Kelly | `(WR × avg_win - LR × avg_loss) / avg_win` | ≥ 0.005 | -0.01 ≤ K < 0.005 | < -0.01 |
| Aggregate EV (pip) | mean of pnl_pip | ≥ -0.10 | -0.30 ≤ EV < -0.10 | < -0.30 |
| Wilson 95% lower (WR) | Wilson score lower | ≥ BEV_WR | BEV_WR-3pp ≤ Wilson < BEV_WR | < BEV_WR-3pp |
| Cell-level Bonferroni | K = locked cell 数 (15) | 全 cell post-LOCK で raw Kelly 改善 | partial | 1 cell でも raw Kelly < pre-LOCK |

**最終判定**: 4 指標すべて ACCEPT 帯 → **ACCEPT** / 1 つでも REJECT 帯 → **REJECT** / それ以外 → **NEEDS_MORE_EVIDENCE** (audit 期間延長 +7 日)

BEV_WR は `wiki/analyses/friction-analysis.md` から pair × mode 加重平均で算出 (本タスクで凍結値を decisions/ に記録)。

```

機能:
1. `--trades` JSON を読み込み、bucket separation を厳格適用
2. TRUE_LIVE 内で `timestamp >= lock_deploy_ts` filter
3. 4 指標を計算、本ファイル §3 の cutoff と照合
4. 各 15-cell の post-LOCK raw Kelly を pre-LOCK と比較 (pre-LOCK 値は decisions/ から読み込み)
5. ACCEPT / NEEDS_MORE_EVIDENCE / REJECT verdict を Markdown レポートで出力
6. SHADOW row 混入を assertion で検出、混入時は abort
7. XAU symbol を必ず除外 (assertion で確認)
8. `--dry-run` モードで sample data + cutoff 表示のみ
