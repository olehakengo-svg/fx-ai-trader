# 2. Pre-Registration LOCK 2nd attempt (R1)

**ファイル**: `knowledge-base/wiki/decisions/pre-reg-ob-retest-h1-1095d-2026-05-18.md` (新規)

## 2.1 Hypothesis (LOCKED, 1st と同一)

H1 TF では SL/ノイズ比 (~30-50pip SL vs ~5-8pip wick noise) と spread 占有率 (0.7pip / 40pip SL = 1.75%) が改善し、OB 構造の institutional anchoring が機能。**1st attempt で USD_JPY/EUR_JPY は質的に PASS 圏内**だったが N 不足で確定不可。3y データ予算で N≥200 を満たし、各 pair の WR/Wilson_lo/EV/PF が **365d と同水準を保つ** なら真 PASS と確定。

## 2.2 PASS / FAIL 基準 (LOCKED, 1st と完全同一)

5 pair 全て (USDJPY, EURUSD, GBPUSD, EURJPY, GBPJPY) で:

**PASS**: **少なくとも 1 pair が** 全て満たす:
- N ≥ 200
- WR ≥ 44.0%
- Wilson_lo (95% CI) ≥ 0.40
- EV ≥ +0.20 pip/trade (spread+slippage 摩擦控除後)
- PF ≥ 1.10
- WF (3 folds) h1 / h2 / h3 全て EV ≥ 0

**FAIL**: 上記いずれか満たさず → `enabled = False` 維持。

## 2.3 Bonferroni 補正

m = 5 (pair 数、1st と同) → α = 0.05/5 = 0.01。Wilson_bf_lo は z=2.576 (99%) で別途算出して併記。

## 2.4 マルチプル検定範囲

**パラメータ sweep 禁止** (1st と同 LOCKED parameter)。**期間以外の post-hoc tweak 禁止**。
GBP_USD 含む 5 pair 全 BT 必須 — post-hoc pair selection は HARKing (feedback_partial_quant_trap)。

## 2.5 1st pre-reg との関係

- 1st pre-reg (365d) は **FAIL 確定**、変更しない
- 本 2nd pre-reg は **データ予算拡張**のみ。期間以外のパラメータ・基準は完全同一
- 1st FAIL は「365d データ予算では確定不可」、2nd は「3y データ予算で確定」と区別
