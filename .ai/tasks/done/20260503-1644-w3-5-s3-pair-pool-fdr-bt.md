# Strategy Specification (Wave 1 と同一 literal mapping を 6 pair に展開)

## Signal (各 pair で同じロジック)

`Δdealer_long_t = change_in_dealer_long_all` (CFTC TFF 報告週 t)
`Δdealer_short_t = change_in_dealer_short_all`

```
if Δdealer_long_t > 0 and Δdealer_short_t < 0:
    side = BUY
elif Δdealer_long_t < 0 and Δdealer_short_t > 0:
    side = SELL
else:
    side = HOLD (no entry)
```

# Statistics — Verdict Matrix v1 §2 (各 pair 単独で全 7 軸)

各 pair の戦略リターン系列 (週次, N≈580 介入除外後) に対し:

1. **N (samples)** — 報告週ベース
2. **WR (win rate)** — リターン > 0 の比率
3. **PF (profit factor)** — sum(positive returns) / |sum(negative returns)|
4. **Wilson 95% CI lower bound** — WR の信頼区間下限
5. **OOS/IS PF** — 70/30 split (in-sample 2014-01 〜 2022-08, out-of-sample 2022-09 〜 2026-04), OOS PF が IS PF の 0.7× 以上
6. **Sharpe (annualized)** — weekly returns を sqrt(52) で年率化
7. **Kelly fraction** — `f* = (WR × avg_win - (1-WR) × avg_loss) / avg_win` (cap at 0.25)

判定帯 (matrix v1 §2 整合):
- **A 帯**: PF≥1.30, Wilson lo≥0.55, Sharpe>1.0, Kelly>0.05
- **B 帯**: PF≥1.10, Wilson lo≥0.50, Sharpe>0.5, Kelly>0
- **C/Reject**: それ以下

# Statistics — Pool-Level (BH FDR + Portfolio)

## Benjamini-Hochberg FDR

各 pair の **戦略リターン平均が 0** の null hypothesis に対し **t-statistic 1-side p-value** を計算 (Welch t-test, sample mean / SE)。

```
1. 6 pair の p-value を昇順ソート: p_(1) ≤ p_(2) ≤ ... ≤ p_(6)
2. 各 i (1..6) で q-value 計算: q_(i) = p_(i) × 6 / i
3. q_(i) ≤ 0.10 を満たす最大 i を見つける → 対応する pair (および全ての p ≤ p_(i) の pair) を BH FDR-significant
```

**Pre-reg LOCK**: 本タスク開始時点で m=6, q=0.10, 6 pair の名前を **このタスクファイル内で固定**。BT 実行後に pair の追加・除外・q 緩和は禁止 (memory `feedback_success_until_achieved` 整合)。

## Portfolio metrics (BH-significant pairs のみで構成)

- **Equal-weight portfolio Sharpe**: BH-sig pairs を 1/k 重みで合成
- **Pairwise correlation matrix**: 全 6 pair の戦略リターン相関 → H2 検証 (correlation < 0.6 → 独立性 OK)
- **Diversification ratio**: portfolio Sharpe / max(individual Sharpes) — 1.0 超なら多角化恩恵あり

# Validity Checks

## Null bootstrap (pool-wide, 必須)

各 pair で **戦略リターン系列を 1000 回シャッフル** (時系列構造を破壊) → 6 pair × 1000 回 = 6000 null sample。
実 t-statistic の rank が **null 分布の 95th percentile** を超える pair を確認。
**fail 条件**: 実 t-stat が null 95th を超えない pair が BH-sig 判定された場合 → BT 実装バグ疑いで再点検。

## Regime concentration (memory `feedback_cohort_time_check`)

各 pair で **年次別** (2014..2026) WR/PF を表化。Wave 1 USDJPY で 2018/2022 trend year に edge 集中していた現象が他 pair でも見られるか確認。
**flag 条件**: 単一年で全 PnL の 50% 超を稼いでいる pair → matrix v1 §3 に従い verdict 記述に明記 (regime-dependent edge の警告)。

## Wave 1 USDJPY regression test

本タスクの BT 実装で **USDJPY 単独** を走らせた時、Wave 1 baseline (PF=1.21, Wilson lo=0.470) が **±5%** 以内で再現できることを `tests/test_s3_pair_pool_fdr.py` で assert。再現できなければ実装バグ → 修正してから他 pair に展開。

## Sanity sample (memory `feedback_codex_mock_test_trap`)

各 pair で **直近 10 件のシグナル** を tabular 出力 (date, side, entry_price, exit_price, return_pip, win/loss) → BT スクリプト実行時に表示し、目視で COT 報告週と価格動向の整合を確認。**self-mock のみの test pass で verdict 出すこと禁止**。
