# 0. なぜこのタスクか

`GBP_USD_15m.parquet` が worker 側 cache に欠落。MASSIVE_API_KEY は user が設定済み (2026-05-05)。

W4-Meta C を per-pair に分割した理由: 元の C は 6 pair × 4500 日 fetch = 60-120 分の長時間タスクで Render container restart cycle (~1-3h) と衝突して orphan 連発。1 pair なら ~5-10 分で完結予定。

# 1. 仕様

## Step 1: API 経路試行

```python
import os
from modules.data import fetch_ohlcv_massive
import pandas as pd

if not os.environ.get("MASSIVE_API_KEY"):
    print("MASSIVE_API_KEY missing — fallback to resample")
    # Step 2 へ
else:
    df = fetch_ohlcv_massive("GBP_USD", "15m", days=4500)  # ~12 年
    df.to_parquet("data/cache/massive/GBP_USD_15m.parquet")
```

## Step 2: 5m → resample fallback (API 不可時)

```python
df_5m = pd.read_parquet("data/cache/massive/GBP_USD_5m.parquet")
df_15m = (df_5m.resample("15min", label="right", closed="right")
                .agg({"Open":"first","High":"max","Low":"min","Close":"last","Volume":"sum"})
                .dropna())
df_15m.to_parquet("data/cache/massive/GBP_USD_15m.parquet")
```

## Step 3: 検証

- start_date < 2024-01-01
- end_date > 2026-04-01
- OHLC 値 NaN なし
