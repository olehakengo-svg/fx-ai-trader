## 3. BT 仕様 (LOCK)

### 3.1 入力データ
| ソース | パス | フィルタ |
|---|---|---|
| Bar OHLC | `data/cache/massive/USD_JPY_5m.parquet` | 全期間 |
| Frozen signals | `data/chart_patterns.db.chart_pattern_signals` | `pattern_id IN (8, 11, 9)` (triple_bottom=8, triple_top=11, inv_h&s=9) |
| Spread profile | `data/chart_patterns.db.chart_pattern_bt_spread_profile` (W2a 実測 24h profile) | `pair='USD_JPY'` |

### 3.2 Trade simulation rules (LOCK)
- **Entry**: `signal_ts + 1 bar` の open
- **Time filter**: `12 <= hour(signal_ts UTC) < 16` (London_NY overlap, 4 hours)
- **Spread**: hour-of-day empirical from W2a `spread_profile` (固定 1.5p ではなく)
- **SL**: 既存 frozen `sl_px` (W1P0 LOCK)
- **TP**: `entry ± (sl_distance × 1.25)` で **再計算** (rr=1.25 enforced)
- **Max hold**: 30 bars (rr=1.25 で TP がやや遠くなるため拡張、W2 の 20 bars から増)
- **MAFE basis**: entry_price (`feedback_spread_basis_for_mafe`)
- **Intrabar TP/SL ambiguity**: 同 bar で両 hit したら **両方の解釈で BT** (SL-first / TP-first) し、verdict 差分を doc に明示 (W2 の SL-first 単一仮定よりロバスト)

### 3.3 OOS / WF 設計

N 不足想定のため:

| Split | Train | Test |
|---|---|---|
| OOS-1 | 2014-2022 | 2023-2026.04 |
| WF-3folds (補助) | 2014-2018 / 2014-2020 / 2014-2022 | 2019-2020 / 2021-2022 / 2023-2026.04 |

OOS-1 を pre-registration の 主 verdict、WF は補助診断。

### 3.4 Path-aware 改善
W2 では `chart_pattern_bt_trades` のみを基に simulate していた。W2b では:
- intrabar TP-first / SL-first の両解を出す
- timeout exit 時の MAFE/MFE が存在しないトレードでは BT 行を捨てるのではなく `exit_at_close` で記録
- spread を hour-of-day で適用

## 4. SQLite DDL (LOCK)

```sql
CREATE TABLE IF NOT EXISTS chart_pattern_w2b_trades (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    candidate_id TEXT NOT NULL CHECK (candidate_id IN ('C1','C2','C3')),
    signal_id INTEGER NOT NULL,
    pattern_id INTEGER NOT NULL,
    pair TEXT NOT NULL,
    timeframe TEXT NOT NULL,
    direction TEXT NOT NULL CHECK (direction IN ('BUY','SELL')),
    intrabar_resolve TEXT NOT NULL CHECK (intrabar_resolve IN ('SL_FIRST','TP_FIRST')),
    entry_ts TEXT NOT NULL,
    entry_px REAL NOT NULL,
    sl_px REAL NOT NULL,
    tp_px REAL NOT NULL,                 -- recomputed at rr=1.25
    exit_ts TEXT NOT NULL,
    exit_px REAL NOT NULL,
    exit_reason TEXT NOT NULL CHECK (exit_reason IN ('TP','SL','TIMEOUT')),
    spread_pips_applied REAL NOT NULL,    -- hour-of-day empirical
    pnl_pips REAL NOT NULL,
    mafe_pips REAL NOT NULL,
    mfe_pips REAL NOT NULL,
    hold_bars INTEGER NOT NULL,
    is_train_oos TEXT NOT NULL CHECK (is_train_oos IN ('TRAIN','OOS')),
    wf_fold INTEGER,                      -- 1/2/3 or NULL for OOS-1 single split
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX IF NOT EXISTS idx_cpw2b_cand ON chart_pattern_w2b_trades(candidate_id, intrabar_resolve, is_train_oos);

CREATE TABLE IF NOT EXISTS chart_pattern_w2b_verdicts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    candidate_id TEXT NOT NULL,
    pattern_id INTEGER NOT NULL,
    intrabar_resolve TEXT NOT NULL,
    eval_split TEXT NOT NULL CHECK (eval_split IN ('OOS_1','WF_1','WF_2','WF_3','TRAIN')),
    n INTEGER NOT NULL,
    wr REAL NOT NULL,
    ev_pips REAL NOT NULL,
    pf REAL,
    wilson_lo_95 REAL NOT NULL,
    bev_wr REAL NOT NULL,
    bonferroni_p REAL NOT NULL,
    bonferroni_alpha REAL NOT NULL,        -- 0.05/3 = 0.01667 (m=3 candidates)
    kelly REAL NOT NULL,
    max_dd_pips REAL NOT NULL,
    verdict TEXT NOT NULL CHECK (verdict IN ('PROMOTE','SHADOW','REJECT','INSUFFICIENT')),
    verdict_reason TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    UNIQUE(candidate_id, intrabar_resolve, eval_split)
);
```

DB path: `data/chart_patterns.db` (append、既存表は read-only)

## 5. 受入条件 (Pre-registration LOCK)

各 candidate × intrabar_resolve × OOS_1 で以下を計算し、verdict を:

| Verdict | 条件 |
|---|---|
| **PROMOTE** | OOS_1 N≥30 AND Wilson_lo > BEV AND PF≥1.5 AND Bonferroni p<0.0167 AND Kelly>0 AND WF 全 fold PF>1.0 |
| **SHADOW** | OOS_1 N≥30 AND Wilson_lo>BEV AND PF≥1.2 (PROMOTE 条件の弱版) |
| **REJECT** | Wilson_lo ≤ BEV OR PF<1.0 |
| **INSUFFICIENT** | OOS_1 N<30 |

Bonferroni m=3 (cells), α/m=0.01667。

intrabar SL-first vs TP-first の verdict が分かれる場合は **保守的に SL-first を採用**、TP-first は doc に併記。
