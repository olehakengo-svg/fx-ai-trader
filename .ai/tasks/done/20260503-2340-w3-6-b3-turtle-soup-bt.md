# Hypothesis (仮説)

§B-3 Turtle Soup (Linda Raschke "Street Smarts") は **20-day Donchian 高安 breakout の失敗トレードを逆張る** 構造で、**S2 Turtle Donchian breakout (W3-2 で B/Shadow promote 済) の設計上の hedge** である。両者を同 pair で同時運用すると、breakout 成功時は S2 が獲り、breakout 失敗時は Soup が獲るため、PnL 系列の 30 日 rolling correlation が負にふれることが期待される。**ロードマップ前進条件**:

1. Turtle Soup 単独で USDJPY M5 12.3年 BT が verdict matrix v1 の **B 帯**を pre-reg primary cell で通過 (Wilson_lo>0.42, PF>1.2, OOS/IS>0.6, Bonferroni p<0.10, Sharpe>0.5, Kelly>0.05)。
2. Null bootstrap (1000 shuffles) で empirical PF が 95th percentile を超える (= label-shuffle null と区別がつく)。
3. S2 Turtle Donchian (W3-2 primary cell) との **rolling 30-day daily-PnL correlation 中央値 ρ_med < -0.10**。負相関 (hedge 性) が無いと Soup を入れる意味がない。
4. 単年集中 max_year_share < 0.50 (S4 で 90.7% に痛い目を見たのを繰り返さない `feedback_cohort_time_check`)。

これら 4 条件が揃えば **Wave 3 Tier 2 1/3 充足、S4 reject の補充完了 → Gate 1 のポートフォリオ alpha 多様化が前進**。1 つでも欠ければ academic only に降格。

# Strategy specification (PRE-REGISTERED, do not modify)

## Setup (20-day Donchian breakout failure detection)

M5 parquet を D1 に resample (UTC day). 各 trading day について:

- `donchian_high(20)` = 過去 20 trading days の prev-day high の max
- `donchian_low(20)` = 過去 20 trading days の prev-day low の min

当日 M5 bars を chronological にスキャン:

- **Up-breakout 発火**: 当日 high が `donchian_high(20)` を上抜けた最初の M5 bar。breakout_price = `donchian_high(20)`
- **Down-breakout 発火**: 当日 low が `donchian_low(20)` を下抜けた最初の M5 bar

## Entry trigger (failed breakout reversal)

Breakout 発火後 `failure_window` bars 以内 (M5 bar count) に price が **breakout 水準を再度逆方向に抜ける** = 失敗確認:

- **Up-breakout 失敗 → SHORT**: breakout 発火後 N bars 以内に M5 close が `donchian_high(20) - 5pip` 以下に戻れば、その bar の close で SHORT entry
- **Down-breakout 失敗 → LONG**: 対称 (`donchian_low(20) + 5pip` 以上に戻れば LONG)

failure_window 期間内に逆抜けが起きなければ trade なし (breakout success とみなす — S2 が獲る領域)。**1 トレード/day max** (最初の trigger only)。

## Exit

- **Stop loss**: setup bar (breakout fired bar) の反対端 ± 5 pip 静的
- **Profit/time exit** (`exit_method` 軸):
  - `50_trailing`: best price から `0.5 × donchian_range` (donchian_range = prev_high - prev_low) trail
  - `100_trailing`: 同じく `1.0 × donchian_range` trail (より permissive)
  - `fixed_time`: trail なし、`session_boundary` 時刻に強制 close
- **Hard time stop**: `session_boundary` (NY_close 21UTC / London_close 16UTC / H24)

## Filters / regime exclusions (no others)

- **介入帯 OFF**: prev_close ≥ 158.000 で翌日 OFF
- **介入日除外**: catalog `wiki/learning/global-retail-fx-edges-2026-05-03.md` §B-2 の 8 件 BoJ 日 (S4 と同一 source) を setup から除外。前日と当日いずれかが該当なら非エントリー。**catalog から正規表現で 8 件取得 (S4 と同じ load 方式)、見つからなければ `INTERVENTION_LIST_MISSING` で abort**
- **No HMM gate. No MA gate. No ATR gate.** S4 で証明済の過剰フィルタ厳禁 (`feedback_ma_filter_breaks_mr`, `feedback_hmm_gate_same_trap`)
