## 2. 仮説

- **H1**: 12 patterns 中、少なくとも 1 つは N≥100 で Bonferroni-significant (m=12, α/m=0.00417) edge を持つ
- **H2**: パターン #2 (rising_wedge) と #5 (falling_wedge) は教科書では順張り/逆張り両説があり、BT で実方向が決まる (literal vs inverted; S3 COT 教訓と同様)
- **H3**: double_top / double_bottom の高頻度 (4869/4666) は overlap exposure で Kelly が圧縮される可能性 → exposure dedup 必須
- **H4 (反証用)**: 全 12 patterns で Wilson lo < BEV または PF < 1.0 なら、ATR-based 検出器自体が edge を持たない (LOCK 解除して幾何条件再検討)

## 3. BT 仕様 (LOCK)

### 3.1 入力データ

| ソース | パス | フィルタ |
|---|---|---|
| Bar OHLC | `data/cache/massive/USD_JPY_5m.parquet` | 全期間 (2014-01-02 〜 2026-04-30, 903828 bars) |
| Frozen signals | `data/chart_patterns.db` table `chart_pattern_signals` | `pair='USD_JPY' AND timeframe='M5'` (22,094 rows) |

### 3.2 Trade simulation rules (LOCK)

- **Entry**: `signal_ts + 1 bar` の open (slippage 回避、bar-close gate との一致)
- **Spread cost**: USD_JPY = 1.5 pips (両建て、entry+exit 計 1.5 pips を pnl から差引)
- **SL/TP**: signals 表の `sl_px` / `tp_px` (W1P0 で固定済み)
- **Max hold**: 20 bars (1.67 hours @ M5) → 到達せず timeout なら exit at close[entry+20] − spread
- **MAFE basis**: `entry_price` 基準 (signal_price ではない、`feedback_spread_basis_for_mafe`)
- **Direction**:
  - Pattern #1-#3, #7-#9: BUY (long)
  - Pattern #4-#6, #10-#12: SELL (short)
  - Pattern #2/#5 wedge は **literal direction で BT、reversed direction でも別途 BT**、両方の Verdict を doc に併記して post-hoc validity で決定

### 3.3 Exposure dedup (H3 対策)

同一 timestamp で複数 pattern が fire した場合:
- **Pattern-isolated BT**: 各 pattern を独立に BT (overlap を許す) → cell verdict 用
- **Pattern-arbitration BT**: 同 timestamp に複数 fire 時は `confidence_score DESC, pattern_id ASC` で 1 件のみ採用 → portfolio Kelly 用

両方の結果を doc に併記。

### 3.4 Walk-Forward (WF) 構成 (LOCK)

3 folds, expanding window:

| Fold | Train | Test |
|---|---|---|
| 1 | 2014-2018 | 2019-2020 |
| 2 | 2014-2020 | 2021-2022 |
| 3 | 2014-2022 | 2023-2026.04 |

各 fold で Test 期間の N/WR/EV/PF/Kelly を独立に算出。

## 4. SQLite DDL (LOCK)

```sql
-- 個別 trade レコード
CREATE TABLE IF NOT EXISTS chart_pattern_bt_trades (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    signal_id INTEGER NOT NULL,             -- chart_pattern_signals.id 参照
    pattern_id INTEGER NOT NULL,
    pattern_name TEXT NOT NULL,
    direction TEXT NOT NULL CHECK (direction IN ('BUY','SELL')),
    pair TEXT NOT NULL,
    timeframe TEXT NOT NULL,
    entry_ts TEXT NOT NULL,
    entry_px REAL NOT NULL,                 -- 実 fill (signal_ts+1 bar open)
    exit_ts TEXT NOT NULL,
    exit_px REAL NOT NULL,
    exit_reason TEXT NOT NULL CHECK (exit_reason IN ('TP','SL','TIMEOUT')),
    pnl_pips REAL NOT NULL,                 -- spread 込み
    mafe_pips REAL NOT NULL,                -- max adverse excursion (entry_px 基準)
    mfe_pips REAL NOT NULL,                 -- max favorable excursion
    hold_bars INTEGER NOT NULL,
    bt_run_id TEXT NOT NULL,                -- 'isolated' / 'arbitrated' を区別
    arbitration_loser_count INTEGER DEFAULT 0,  -- arbitrated mode で負けた competing patterns
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX IF NOT EXISTS idx_cpbt_pattern ON chart_pattern_bt_trades(pattern_id, bt_run_id);
CREATE INDEX IF NOT EXISTS idx_cpbt_signal ON chart_pattern_bt_trades(signal_id);

-- Cell verdict (pattern 単位の集計、BT 完了時に書き込み)
CREATE TABLE IF NOT EXISTS chart_pattern_bt_verdicts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    pattern_id INTEGER NOT NULL,
    pattern_name TEXT NOT NULL,
    pair TEXT NOT NULL,
    timeframe TEXT NOT NULL,
    bt_run_id TEXT NOT NULL,                 -- 'isolated' / 'arbitrated' / 'reversed' (wedge only)
    n INTEGER NOT NULL,
    wr REAL NOT NULL,                        -- 0..1
    ev_pips REAL NOT NULL,
    pf REAL,                                 -- nullable for pf=inf
    wilson_lo_95 REAL NOT NULL,
    bev_wr REAL NOT NULL,                    -- breakeven WR (spread / (TP+SL))
    bonferroni_p REAL NOT NULL,
    bonferroni_alpha REAL NOT NULL,          -- 0.05/12
    kelly REAL NOT NULL,
    max_dd_pips REAL NOT NULL,
    wf_fold1_pf REAL,
    wf_fold2_pf REAL,
    wf_fold3_pf REAL,
    wf_all_folds_positive INTEGER NOT NULL,  -- 0/1
    verdict TEXT NOT NULL CHECK (verdict IN ('PROMOTE','SHADOW','REJECT','INSUFFICIENT')),
    verdict_reason TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    UNIQUE(pattern_id, pair, timeframe, bt_run_id)
);
```

DB path: `data/chart_patterns.db` (W1P0 と同一 DB に append)

## 5. 統計条件 (受入 LOCK)

各 cell (pattern) について以下を計算:

| Metric | 計算 | 通過条件 |
|---|---|---|
| N | trade 数 | ≥ 100 (< 100 は INSUFFICIENT) |
| WR | wins / N | — |
| Wilson lo 95% | Wilson interval lower bound | > BEV_WR |
| BEV_WR | spread / (avg_TP_dist + avg_SL_dist) | 各 pattern 個別計算 |
| EV | mean(pnl_pips) | > 0 |
| PF | sum(wins) / abs(sum(losses)) | ≥ 1.3 |
| Bonferroni p | binomial test p-value | < 0.05/12 = 0.00417 |
| WF | 3 folds 個別 PF | 全 fold > 1.0 |
| Kelly | (WR - (1-WR)/payoff) / 1 | > 0 |
| Max DD | running min of cumulative pnl | informational |

### 5.1 Verdict マトリクス

| 結果 | Verdict |
|---|---|
| 全条件通過 + Kelly > 0.05 | **PROMOTE** (Wave 4 LIVE candidate) |
| Wilson/PF/Bonferroni 通過、WF 1 fold 失格 OR Kelly < 0.05 | **SHADOW** (W3 sweep へ) |
| Bonferroni 失格 OR Wilson lo ≤ BEV | **REJECT** |
| N < 100 | **INSUFFICIENT** |

### 5.2 Wedge 方向反転判定 (Pattern #2/#5)

literal と reversed の両 BT を実行、PF が高い方を採用:
- どちらも PROMOTE/SHADOW なら高 PF 採用 + 反対方向は記録のみ
- literal が REJECT で reversed が PROMOTE/SHADOW なら **方向反転を doc に明示**、戦略 doc を更新
