## 【作戦候補 #1】🔴 配管診断（最高優先）— `r2_shadow_demoted_cell` 固着の「N蓄積サイクル破壊」構造の特定

- **仮説**: Shadow 降格セルが昇格に必要な N 蓄積の機会そのものを遮断しており、「昇格条件 N≥30 待ち」と「N が増えない構造」が同時に成立するデッドロックが発生している
- **根拠**: scalp 系 3 戦略で `r2_shadow_demoted_cell` が累計 5,274 件超。これは「シグナルが生成されているが昇格カウントに加算されていない」か「シグナル生成前に遮断されて N カウンタ自体がインクリメントされない」かのいずれか。前者と後者では対処が根本的に異なるため、どちらが起きているかの特定が先
- **学術的裏付け**: Aldridge (2013) *High-Frequency Trading* §4「Gateway filter の上流配置ミスはシグナル生成統計を歪め、バックテストとライブの乖離を拡大する」— フィルタが evaluation ループの内側か外側かで N カウントの定義が変わる点を指摘
- **失敗シナリオ**: 「遮断が設計通り」であれば問題なし。ただしその場合、昇格への経路が存在しないことを明示的に設計文書に記載する必要がある（現状不明）
- **摩擦試算**: 配管バグ診断はスプレッドコスト対象外。ただし N 蓄積が機能しない期間は全ての GO 基準評価が無効化される
- **GO基準（診断完了の定義）**: 「r2_shadow_demoted_cell ブロック時に、対象セルの shadow_N カウンタが +1 されるか否か」を 1 件のログで確認できること。Y/N のどちらかが判明すれば診断完了
- **前回との差分**: 2026-10-24 の候補 #1 は「降格基準と復帰条件の非対称性」にフォーカスしたが、本日は「N カウントが加算されているかどうか」という **より上流の問い** に絞る。非対称性の議論は N が蓄積されていることが前提であり、蓄積がゼロなら先に確認すべき問いが変わる
- **推奨優先度**: 🔴 高 — carry_dip_accumulator 以外の全戦略の昇格経路がこの一点にかかっており、これが解決しないと他の作戦候補はすべて評価不能のまま

## 【作戦候補 #2】🟠 既存Shadow在庫消化 — `carry_dip_accumulator` N=4 の「エントリー条件充足頻度」の事前予測

- **仮説**: USD_JPY ATR%ile=34% の低ボラ環境において carry_dip_accumulator が N=30 に到達するまでの期間を、現在の充足頻度から逆算することで「いつ昇格審査が可能になるか」の見通しを持てる
- **根拠**: Cutoff 後 N=4、稼働期間は約 7 ヶ月（2026-04-08〜2026-10-27）。単純計算では月平均 N ≒ 0.57 件/月 → N=30 到達に **約 46 ヶ月（≒ 4 年）**。これは明らかに設計想定と乖離しており、エントリー条件の閾値か対象期間の定義が実環境に合っていない可能性を示唆する。ただし「Cutoff」の定義次第で計算が大きく変わるため、まず Cutoff 基準日の確認が必要
- **学術的裏付け**: Pardo (2008) *The Evaluation and Optimization of Trading Strategies* §2「Out-of-sample period の N が不足した状態でのパラメータ凍結は、戦略の実力ではなくノイズを評価している」— N=4 の現状はまさにこの状態
- **失敗シナリオ**: Cutoff 基準日が最近（例：2026-10-01）であれば月 N は適正範囲の可能性があり、「4年待ち」の計算は杞憂となる。確認せずに閾値変更を議論すると誤った修正につながる
- **摩擦試算**: 戦略変更なし。診断のみのため摩擦コスト発生しない
- **GO基準**: 「Cutoff 基準日から現在までの実稼働日数」と「エントリー条件が充足された総回数（N=4 の根拠ログ）」を照合し、1 日あたりの充足頻度を確定すること
- **前回との差分**: 2026-10-22 の候補 #1 は「N=30 到達時の昇格審査自動起動の実動確認」だった。本日は **その前段として「N=30 にいつ到達するか」の期間推定** に絞る。自動起動の確認は N 到達見込みが現実的な場合にのみ意味を持つ
- **推奨優先度**: 🟠 中 — carry_dip_accumulator はシステム唯一の生きた評価ラインだが、到達見込みが数年単位なら「昇格待ち」という現状維持方針そのものの再検討が必要になる。その判断材料として本日中に確認できる
