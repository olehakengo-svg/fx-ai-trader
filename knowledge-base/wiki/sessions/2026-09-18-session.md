## 3. 一番大きい発見 (A-1)

**「梯子の一番上の段」が、実は梯子ではなく事後報告だった。**

pin 版 lexicon の level 5 は `レートチェック` (act に先行する talk) と
`介入を実施 / 行った / 行い / いたし / 行う` `平衡操作を実施` (act の事後ナレーション) を
同じ段に置いていた。corpus 全期間 512 会見を実査すると、**L5 判定 9 件はすべて後者**で、
`レートチェック` 由来は 0 件。

これを L≥4 の primary 検出器に入れると、検出器は「介入が起きた直後の会見で介入の話をしている」
ことを読んで介入を"予測"する。**look-ahead が検出器の定義の内部に入る**。family A の estimand は
hit/FA 較正そのものなので、これは推定量を壊す blocking 欠陥だった。

面白いのは、これが scan 第5次 §1.2 の欠陥 (negative sample 欠落 → precision 水増し) と
**同じ向きの誤り**で、場所だけがデータ側から検出器定義側に移っていた点。
「FP 率較正が本 family の価値」という一文を両方の場面で使っている。

修正は **lexicon を触らずに検出器側の水準写像で行った** — pin (`569dbe3f`) は比較可能性の
凍結なので、そこを動かすと凍結の意味が消える。

## 5.5 派生タスク: hunt_events の pytest 汚染を logger 側で遮断 (PR #266、rule:R3)

凍結 PR の full suite 実行で `raw/hunt_events/2026-09-18.jsonl` が生成されたため、コミット前に
中身を実査した。MEMORY に記録済みの判別署名「adx が整数 ∧ atr_price==0.001」を当ててみると、
**生成 36 行のうち合致は 12 行 (33%) のみ**。残り 24 行は実バーを再生する fixture 由来で
`adx=26.40232975431798, atr_price=0.09089354405798802` のような実測値らしい float を持ち、
**署名を素通りする**。

2026-09-17 のスキャンで「誤判別ゼロ」と確認していたのは **precision** の話 (合致した行は本当に合成)
であって、**recall は測っていなかった**。署名は「合成だと確実に分かる部分集合」であって合成集合ではない。
⇒ 事後フィルタは防御になりえないので、**書込みそのものを止めた**。

`HUNT_EVENT_LOG_MODE` (`auto` 既定 / `on` / `off`) を追加し `auto` は pytest 中の書込みを抑止。
logger 自身のテストは `mode=on` + `HUNT_EVENT_LOG_DIR`=tmp_path で行えるようにしたので、
抑止を入れても logger がテスト不能にならない。full suite 後に hunt_events 無変化を実測、回帰 pin 11 本。

## 5.8 pass-2 執行 — ❌ FAIL、そして自分の凍結仕様の欠陥 (PR #270)

pass-1 で pass-2 が解錠されたので、同じセッションで測定まで走らせた
(§10.3 の「readout を commit してから pass-2」を守り、#268 が main に着地してから実行)。

**verdict: FAIL。** J = 0.2978 / p = 0.1074 > α = 0.05。TPR 3/7 / FPR 144/1101。

### なぜこの FAIL は情報量があるか

走らせる前に **positive control** を通した — 実 armed 系列に合成ラベルを置き、
「陽性が全て armed 窓内」なら k=7 でも **p = 0.0027** に達することを確認した。
つまり**強い効果があれば通せた検定で、通らなかった**。E23 の UNDERPOWERED
(そもそも測れなかった) とは性質が違う。

### 一番効いた caveat

pass-1 で「暦年ちょうど 2 / 供給の 5/7 が片山期」を caveat として書き、
「2022 の 2 本だけで結論が反転しないか点検せよ」と自分に課した。点検の答えは
**2022 期 J=0.2494 / 2026 片山期 J=0.0484**。さらに event 単位で見ると
**全 7 event のうち何かを当てたのは 2 本だけ** (2022 が 1 / 2026 が 1) で残り 5 本は false alarm —
全体 J のほぼ全てを **2022 の 1 event** が担っていた。
検出器は「介入前の梯子」ではなく **2022 の 1 回のエスカレーションの記述**にすぎない。
caveat を書いておいたおかげで、FAIL の中身を正しく読めた。
