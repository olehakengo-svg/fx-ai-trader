## 1. A-1 (blocking): ladder の L5 は「梯子の段」ではなく事後ナレーション

### 1.1 所見 (signal 側のみ)

pin 版 lexicon v1 の LADDER level 5 は
`介入を(実施|行い|行った|いたし|行う)` / `平衡操作を実施` / `レートチェック` を同一段に置く。
corpus 全期間 (2022-01-07〜2026-09-15、512 会見) の L4/L5 駆動語句の内訳:

| 駆動語句 | 出現会見数 |
|---|---|
| L4 `断固` | 17 |
| L5 `介入を実施` | 3 |
| L5 `介入を行う` | 2 |
| L5 `介入を行い` / `介入を行った` / `介入をいたし` / `介入を行い+行った` | 各 1 (計 4) |
| L5 `レートチェック` / `平衡操作を実施` | **0** |

**L5 と判定された 9 会見すべてが、過去形または抽象論の「介入」言及**である。文脈実査 (3 例):

- **2023-09-13**「昨年９月に24年ぶりとなりますドル売り円買いの為替介入を**行い**、続く10月にも…介入を**行った**こと、これも印象に残っている点であります」— 介入の **11 ヶ月後の回顧**。
- **2024-10-01**「為替介入を**行う**というのはある意味まれでなければならない」— 特定の介入を指さない**規範的一般論**。
- **2026-09-08**「日米協調介入を**実施**したときから一切変わっておりません」— 既往介入への言及。

### 1.2 なぜ blocking か

family A の estimand は **先行検出器の較正 (hit / false alarm)** である (§2)。事後ナレーションを
段に数えると、検出器は 2 経路で estimand を壊す:

1. **機械的 hit** — 介入直後の会見はその介入を語るため L5 に上がる。検出器は「起きたことを読んで
   当てる」= look-ahead が検出器定義の内部に入る。hit 率を機械的に押し上げ FA 率を押し下げる。
2. **純ノイズ event** — 2023-09-13 (回顧) / 2024-10-01 (一般論) のように、介入と無関係な文脈でも
   発火する。これは FP 側を不規則に汚す。

どちらも「FP 率較正こそが本 family の価値」(scan 第5次 §1.2、negative 欠損が precision を機械的に
押し上げるという同じ論理) に真正面から反する。

### 1.3 凍結する修正 (lexicon 本体は不改変)

**検出器側の水準写像**として凍結する。pin 版スコアラーの出力 `matched_phrases` を後処理するだけで、
`tools/mof_statements_lexicon.py` の pin (`569dbe3f`) は不変 = 比較可能性の凍結 (§0-4) を維持。

- `L5_LEADING = {レートチェック}` → 水準 5 を維持 (talk が act に先行する唯一の語)
- `L5_RETROSPECTIVE = {介入を実施, 介入を行い, 介入を行った, 介入をいたし, 介入を行う, 平衡操作を実施}`
- **leading 語を含まない L5 会見は、その会見が matched した L1–L4 の最大値へ降格** (無ければ 0)

`平衡操作を実施` も「実施」= 事後形につき retrospective 側。`介入を行う` は文法的には
前向きだが、実観測の唯一の用例が規範的一般論であり、かつ Q&A では
「介入を行うかどうかはコメントを差し控える」型の**拒否構文に埋まって発火しうる**ため、
保守側 (降格) に倒す。**この判断は語句の文法的性質に基づく設計判断であり、ラベルとの
突合による較正ではない。**

> ⚠️ **本修正はデータ較正ではない**という点の自己批判: 「どの語が実際に出現したか」は
> signal 側の観測であり、それを見てから分類規則を決めている。しかし分類の**基準**は
> 「その語が act を事後に述べるか、act に先行するか」という文法的性質のみであり、
> 介入ラベルとの一致度は一度も見ていない。仮に corpus に `レートチェック` が
> 100 件あったとしても同じ規則になる。この非対称性をもって「論拠のみ」の要件を満たすと判断した。

## 2. A-2: rearm は event-to-event で測る

DRAFT §2 の rearm 規約「直近 R 営業日に L≥4 が無いこと」を**水準系列**に対して読むと、
carry-forward T=5 の間も L≥4 が立っているため、**実効不応期が R + T = 25 営業日**になる。
25 営業日 ≈ 35 暦日 > §3 の episode 個別化規約 (gap ≥ 30 暦日) ⇒ **30 暦日ちょうどで隣り合う
2 エピソードに対して、検出器は 2 発目を構造的に取り逃す**。event 単位と outcome 単位が
非可換になる。

**凍結**: rearm は**直前に emit した event から** R 営業日で測る。最小 event 間隔 = R+1 = 21 営業日
(≈ 29–30 暦日) で episode gap 規約と整合し、かつ H=20 の hit 窓 `[e, e+20]` が重ならない
(21 > 20) ため、**trial が清く分割される**(独立性の近似が成立)。

## 3. A-3: (T, R, H) = (5, 20, 20) は論拠で支持 — 据置

| par | 値 | 論拠 (データ較正なし) |
|---|---|---|
| **T** | 5 bd | 会見 cadence は 512 会見 / 4.7 年 ≈ **2.1 回/週**。T=5 営業日は「次の会見 + 余裕 1 回」を覆う最小値。T=3 は会見を 1 回落とすと状態が切れる。T=10 は「2 週間の沈黙」を高位維持と解釈することになり、`no_comment` を de-escalation と読む §2 secondary の設計と矛盾する |
| **R** | 20 bd | §3 の episode 個別化規約 (gap ≥ 30 暦日) と可換にする値。A-2 の修正後、最小 event 間隔 R+1 = 21 bd ≈ 29–30 暦日で規約に一致 |
| **H** | 20 bd | **H = R が必須**。H > R なら隣接 event の hit 窓が重なり trial が従属化、H < R なら不応期内に死角が生じる。R を episode 規約で決めた以上 H は従属的に決まる |

起草時の設計仮説 (5, 20, 20) を**変更する論拠は見つからなかった**ため据置。
候補空間 {3,5,10}×{10,20}×{5,10,20} の他セルは本凍結で恒久的に放棄する (後から動かさない)。

## 4. A-4: 検定統計量を 1 本に確定

**J = P(armed | 介入日) − P(armed | 非介入日)** (day-level Peirce skill score / Youden J)、
explore 窓の全営業日について計算。`armed` = ある event e の `[e, e+H]` に属する日。

§5 の候補 2 本のうち「リード付き overlap 計数」を棄却する理由: overlap 計数は **event 供給量に
比例してスケール**するため、片山期にイベントが集中している (A-6) 状況で「検出器が良い」と
「検出器がよく鳴る」を分離できない。J は両条件付き確率の差で base rate から自由。

- **Null**: episode-block circular-shift (ラベル系列を block 構造保持のまま一様シフト、B=10,000)。
- **片側** (J > 0)、m=1 (primary のみ)、secondary は全て記述。
- **p の下限**: explore 窓の営業日数 ≈ 1,120 ⇒ 相異なるシフト数が B を下回る場合は
  **相異なるシフト全数**を使い、p = (1 + #{J_shift ≥ J_obs}) / (1 + #shifts) と定義する。

## 5. A-5 / A-6: pass-1 gate (label-free) と verdict 数値の凍結

E23 の two-pass (pass-0 census → pass-1 → pass-2) と同じ構造を踏襲する。
**pass-1 は完全に label-free**で、ここで park 判定が出れば explore の look を一切消費しない。

| gate | 条件 (凍結値) | 不通過時 |
|---|---|---|
| **Gate A (特異度)** | armed 営業日 / 全営業日 ≤ **0.25** | FAIL (検出器が常時点灯 = 非特異) |
| **Gate B (供給)** | event 数 ≥ **5** かつ event の**相異なる暦年 ≥ 2** | **UNDERPOWERED / park** |

- **Gate A の 0.25 の論拠**: 設計期待は event 5–8 本 × (H+1)=21 bd ≈ 105–168 bd / 約 1,120 bd
  = 9–15%。その約 2 倍を非特異の閾値に置く。データを見て決めていない (event 数はまだ数えていない)。
- **Gate B の 5 の論拠**: 有効 N = 4 episode blocks に対し、event が 5 本を下回ると 2×2 分割表に
  構造的な空セルが残り「エピソードでのみ鳴る」と「稀にランダムに鳴る」を判別できない。
- **Gate B の「≥2 暦年」(A-6)**: L4 `断固` の年次分布は 2022:3 / 2023:0 / 2024:0 / 2025:0 / 2026:13。
  **2023–2025 は `断固` 皆無**であり、検出器のイベント供給は話者 (鈴木 → 片山) と強く交絡する。
  単一暦年に集中した event 群は「介入前の梯子」ではなく「片山期の語法」を測っている可能性が
  分離できないため、park 扱いとする。

**verdict 固定分岐 (DRAFT §5 の表を数値確定)**

| verdict | 条件 |
|---|---|
| **PASS (記述級)** | Gate A ∧ Gate B 通過 ∧ permutation p ≤ **0.05** (片側、J>0) |
| **FAIL** | Gate A 不通過、または Gate A∧B 通過後に p > 0.05 |
| **UNDERPOWERED / park** | Gate B 不通過 (pass-2 を解錠しない = explore outcome 未接触のまま park) |

PASS でも主張上限は **記述級**のまま (§5 の N=4 blocks 拘束は不変。edge 主張・live 変更ゼロ)。

## 6.5 A-8 (blocking、レビュー由来): 非営業日の会見が検出器から落ちていた

初版の `build()` は営業日カレンダー上でのみ会見日を引くため、**土日・祝日に開催された会見を
黙って無視**していた。corpus 実測で該当 **13 / 512 件**:

| 日付 | 曜日 | 水準 |
|---|---|---|
| 2022-07-16 | 土 | L2 |
| 2023-05-13 | 土 | L1 |
| 2024-05-03 | 金 (憲法記念日) | L2 |
| 2024-05-25 | 土 | L2 |
| 2025-05-04 | 日 | L3 |
| 2026-03-14 | 土 | L3 |
| **2026-05-04** | **月 (みどりの日)** | **L4 `断固`** |
| (他 6 件) | — | L0 |

**仮説的な欠陥ではない** — 2026-05-04 の L4 `断固` は trigger 水準 (X≥4) であり、初版の検出器では
**event をひとつも生まない**。しかも非営業日の会見が集まるのは G7/IMF 総会週末とゴールデンウィーク
= **為替が最も緊張する局面**であり、miss 側のバイアスが最悪の場所に入る。

**凍結する修正**: 非営業日の会見は `next_business_day()` で**翌営業日へ roll forward**、
同一営業日に複数が落ちた場合は max を採る。

*前方*に倒す論拠: 非営業日に行われた発言が市場参加者にとって最初に**作用しうる**のは翌営業日である。
後方 (前営業日) に倒すと、発言が行われる前の日に状態を立てることになり look-ahead になる。

> レビュー (Codex P2) は「週末会見が無視される」と指摘し、corpus 上の L3/L0 例 2 件を挙げた。
> 独立に corpus を全数走査したところ **L4 の実例 (2026-05-04)** が見つかり、指摘より実害が重いことが判明した。
> **凍結前に修正**したのは、凍結後の検出器変更は pre-reg の破棄に等しいため。
