## 0. 共通拘束 (どちらの経路にもかかる算術)

1. **base rate**: explore→OOS 生存 0/18 系統、観測 base rate 4.0% [Wilson 0.7-19.5%]。これは「無料 OHLCV × intraday × リテール摩擦」空間の性質 (監査 viability-1/4)。ただし round5 §3.1 の外部較正 (McLean–Pontiff 58% 減衰 / Hou 65-82% 不通過) が示すとおり、**base rate の相当部分は『公表済み仮説を引く』という母集団選択に由来し、この成分はモダリティ・市場を変えても同行する**。経路 (a)(c) が動かせるのは「摩擦・情報集合・混雑」由来の成分のみ。
2. **希少資源はデータ費用ではなく OOS 窓と敵対的検証工数** (round4 §4 凍結)。起案 1 本 ≈ 敵対的検証 + two-pass + verdict の Claude 工数を消費する。
3. **資本**: NAV ¥275,486 (09-10 実測) / floor ¥262,000 (API 存続) → **可動余剰 ≈ ¥13.5k**。どの経路も「既存口座から取引資本を割く」選択肢は物理的に存在しない。割けるのは (家計側の) データ月額と工数のみ。なお OANDA Gold は status volume keeper が 9 月出来高 $520k/$500k を到達済み (2026-09-17 本番実測、target_reached) で 10 月維持見込み — ただし条件は毎月更新のため、U3 で (ii) 縮退 (keeper 停止) を選ぶと (a) の前提が崩れる。
4. **決裁スリップの既定帰結**: 10-18 に仮決めしなければ実質 (d) = F1 (2027-02-05) の時限 3 系統 (結合 FAIL 確率 ~61-89%) への賭け。これは毎回明記する (packet 規約)。

## 1. 経路 (a) 有償データ

### 1.1 「E22 で決裁点定義済み」の正確な中身 (packet 行 (a) の訂正)

- E22 pre-reg §9 (逐語凍結) が定義した決裁点は「**explore+OOS 全 PASS 時のみ** Databento 調達の user 決裁点に到達」。実際は explore **FAIL** (IC −0.0249 / p=0.760 / stressed-net adverse **−11.2p** — swap −16.2p が gross +8.9p を支配) で**決裁点は不到達 = 台帳 #24 で「Databento 調達決裁は不要化」と記録済み**。
- 現存する定義は FAIL 時凍結の**復活経路**: 「新データ (真正 OTC FX オプション面 = Databento 等有償) + 新 family + 事前差分節 + 新規敵対的検証のみ」。**「即決可能」はこの意味でのみ真** — 買う/買わないの判断自体は追加 feasibility なしに R1 起案できるが、買っても vol モダリティが自動再開するわけではない (新 family + 新敵対的検証が必須)。
- **power caveat の引用規律**: FAIL ≠ falsified (検出力 8-17%) だが、**点推定自体が ≈0 (完全 null)** — 「power 不足だったから買えば見つかる」という購買正当化は estimand 監査規律と緊張する。買う根拠は「EVZ (ATM proxy) と RR/BF (crash 保険価格) は情報が別」という差分のみに置く。

### 1.3 経路 (a) の決裁点設計 (提案)

- **10-15**: E1 verdict を確認。PASS → 供給圧は一時緩和、(a) 購買は再び「急がない」(round4 凍結の再上程条件は片側充足のまま)。UNDERPOWERED / REJECT → 供給圧が上がり、10-18 の仮決めが実質の分岐点になる。
- **10-18 (scan#6)**: (a-1) の **probe 購買 (CME DataMine 歴史、一回性・数百$ 上限) を R1 個別起案するか**を裁定。月額サブスク型 ($2k 級 ≈ ¥300k/月) は現 NAV の M3 完全達成時月次期待 (¥6.5-9.7k) の ~30-45 倍で、**U2 が ¥1M+ に解決しない限り自動 NO**。
- 購買 → データ QA → 新 family 起案 (新敵対的検証必須) の順。購買は family 起案とセットでのみ意味を持つ (単体購買は「読み手のいない write」の再生産)。

## 2. 経路 (c) FX 以外

### 2.3 資本適合の算術 (packet §U4(b) の指摘の (c) への適用)

packet は (b) daily+ クロスセクショナルを「現 NAV では最小ロット粒度で不成立 — 資本が先」と裁定済み。**(c) にも同じ構造がそのまま適用される**: floor 余剰 ¥13.5k では新市場の最小単位すら建たず、live 化は新規資金 = **U2 (資本上限の凍結) の先行決裁が構造的前提**。U2 未決裁のまま (c) を選ぶと「live 変換経路のない研究トラック」になる — それ自体は $0 で可能だが、**weekend_gap の F2 教訓 (OOS PASS が live 約定 0 のまま = PASS→live 変換未実証) の計画的再生産**である。

### 2.4 (c) に残る利点

母集団そのものが変わる (base rate 4% の測定母体の外) + データ費 $0 で S1/S2 は回せる + 統計ハーネス (two-pass / circular-shift / Wilson) は可搬。摩擦・執行層のみ非可搬。

## 4. 推奨 (仮決め案、10-18 上程)

**U4 仮決め = (a) を主経路、(c) は S1 まで。**

1. **(a) が唯一「取引資本を追加せずに」空間を変えられる経路** — NAV floor 制約・OANDA 存続条件と両立するのは (a) だけ。変えるのは情報集合のみで、執行・摩擦・検証の既存資産が全部生きる。
2. 具体形: **10-15 の E1 verdict が PASS 以外なら、scan#6 (10-18) で (a-1) OTC FX オプション面の歴史 probe (CME DataMine、一回性・数百$ 上限) の R1 起案を裁定**。月額型は U2 決裁前は自動 NO。(a-2) CLS は価格照会 ($0) のみ先行。(a-3) Databento CME は 2027-02 (E12 verdict) まで保留 — round4 凍結を維持。
3. **(c) は scan#6 に S1 裁定表 (equity index daily、本メモ §2) を正式添付して物理判定 (口座・資本・執行) を凍結するに留める**。live 経路の解錠は U2 が ¥1M+ に解決した場合のみ — その時点で (c) を (a) と対等の候補に昇格して再裁定。
4. **無決裁 = (d)** (F1 の時限 3 系統・結合 FAIL 確率 ~61-89% への賭け) であることを 10-18 の上程文面に毎回明記する。

決裁の書式: `U4 仮決め: (a) probe [E1 verdict 条件付き] / (c) S1 のみ` の一言で足りる。反映 (registry 期日 + scan#6 議題 + packet 追記) は Claude が自走する。


## 5. リスク・反論 (敵対材料、10-18 上程時に併読)

- 有償データを買っても base rate が動く保証はない — 0/18 の主成分が「公表済み仮説の公表後減衰」(McLean-Pontiff 58% / Hou 65-82%、round5 §3.1 が自認) なら、モダリティ変更 (a) でも市場変更 (c) でも消えない。E22 の実測が先例: 有償 unlock の一歩手前の無料 proxy が完全 null (IC −0.025、点推定 ≈0) だった
- (a-1) の購買正当化に「FAIL≠falsified (power 8-17%)」を使うのは estimand 監査規律 (feedback_audit_past_verdicts) と緊張する — E22 は点推定自体がゼロ近傍で、「買えば見えるはず」は power caveat の誤用になりうる。購買根拠は RR/BF≠EVZ の情報差分のみに限定すべき
- 費用の経済不整合: $2k/月 ≈ ¥300k/月 は現 NAV での M3 完全達成時の月次期待 (¥6.5-9.7k) の ~30-45 倍。U2 (資本上限) 未決裁での月額課金はプロジェクト経済を確実に負にする — 正当化可能なのは一回性 probe (数百$) のみ。そしてこの比較自体が U2 未決裁の帰結 = U4 は単独では閉じず U1/U2 と連動する
- (c) の live 変換不能 PASS 量産リスク: U2 未決裁のまま (c) で PASS を作っても執行できない — weekend_gap F2 (live 約定 0 のまま 2026-12-31 に「PASS→live 変換未実証」認定見込み) の計画的再生産になる
- 工数こそ希少資源 (round4 §4 凍結): (a)(c) 並行起案は敵対的検証・OOS 窓・会計の供給を圧迫し、#27 数え落とし (09-15、round5 §2 で訂正) 型の WIP 会計漏れを再発させうる。現に唯一の着手可能ライン #27 の凍結期日 (09-24) が最優先のまま
- (a) の最大の論拠「執行は既存 FX のまま」は OANDA API 存続 (Gold + 残高 25 万) が前提。9 月出来高は keeper が $520k 到達済み (10 月維持見込み) だが条件は毎月であり、U3 で (ii) 縮退 (keeper 停止) を選ぶと本判定表は無効化される — U3 の帰趨が (a) の前提条件
- 決裁スリップ = 自動的に (d): 10-18 で仮決めしない場合、F1 (2027-02-05) の時限 3 系統 (結合 FAIL 確率 ~61-89%) への賭けが既定挙動として確定していく — 「仮決めの先送り」は中立ではない
- (c) の資本算術は概算: 日経225マイクロの notional/証拠金・店頭 CFD の最小単位とレバ上限は本メモでは概算 [要実測] — 決裁前に一次情報で確認が必要 (MoF URL 推測の教訓: 組み立てた仮定の 404/実在は一次確認まで証拠にならない)。CLS の価格も未取得のまま優先順位を論じている
- E1 first look (10-15) の modal 予想は UNDERPOWERED — この場合「供給圧上昇」と「E1 継続蓄積 (second look 2027-01-06)」が併存し、(a) probe 起案の緊急度判定が曖昧になる。UNDERPOWERED 時の扱いを 10-18 前に一行で事前定義しておくべき
